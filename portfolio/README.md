# Mohammad Pakdoust — Portfolio v2

A lightweight, recruiter-focused portfolio for data analytics, BI, data engineering, and applied AI roles.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy on Vercel

Import the GitHub repository and set the project's **Root Directory** to `portfolio` if these files live inside the profile repository under that folder. No build command or framework preset is required; Vercel can serve this as a static site.
