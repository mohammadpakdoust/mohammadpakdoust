## 🌟 Selected Work

### 📄 [Document-Grounded RAG System](https://github.com/mohammadpakdoust/Document-Grounded-RAG-System)
A grounded question-answering pipeline for PDF documents with retrieval gating, page-level citations, PII handling, prompt-injection defenses, and faithfulness checks.

**Stack:** Python · LangChain · Chroma · Gemini · Jina Embeddings

### 🔍 [Search Engine](https://github.com/mohammadpakdoust/Search_Engine)
A search engine implemented from first principles with text preprocessing, positional inverted indexing, TF-IDF weighting, cosine-similarity ranking, and phrase matching.

**Stack:** Python · Information Retrieval · NLP

### 🧠 [Qwen Mechanistic Analysis](https://github.com/mohammadpakdoust/Qwen-Mechanistic-Analysis)
A team project exploring sparse autoencoders over Qwen2.5-1.5B activations, including feature analysis and causal intervention experiments.

**Stack:** Python · PyTorch · Hugging Face · Sparse Autoencoders

### 🤖 [GenAI Market Research Automation](https://github.com/mohammadpakdoust/GenerativeAI-Market-research)
A multi-agent research workflow that separates web research from synthesis to produce structured market-analysis reports.

**Stack:** Python · CrewAI · Gemini · Serper

### 🎙️ [Local Video Transcription for macOS](https://github.com/mohammadpakdoust/Video-Transcribe-Engine-for-MacOS)
A local-first macOS transcription workflow built around whisper.cpp and FFmpeg, with subtitle output and no cloud upload requirement.

**Stack:** Python · whisper.cpp · FFmpeg · Tkinter
